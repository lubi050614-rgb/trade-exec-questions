# 题目＋对应数据输入

当前仅生产题目与输入数据，不生成标准答案、教师答案、知识卡或学生评测结果。

## 已有产物

- `题目与数据输入.jsonl`：1150道题及其输入引用，不含answer/solution/expected_output字段。
- `题目输入索引.csv`：方便在Excel中按题目或节点筛选。
- `执行输入数据_200标的5日.zip`：可直接解压的完整合成基础数据。
- `input-validation.json`、`input-binding-validation.json`、`input-reproducibility.json`：数据、绑定与重复生成的独立检查。

数据包的股票universe为200个SYN标识，测试日期为2026-11-02至2026-11-06的5个显式日期。日期仅作测试日历，没有冒称已经核验交易所日历或获取真实A股数据。

## 使用方法

在仓库根目录解压数据包；默认生成目录不进Git，数据包和源码随仓库提供：

```powershell
Expand-Archive -LiteralPath 'deliverables/执行输入数据_200标的5日.zip' -DestinationPath 'data/generated/execution-inputs-v1'
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/read-question-input.ps1 -QuestionId P01-S01-Q01 -MetadataOnly
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/read-question-input.ps1 -QuestionId P09-S01-Q01 -AsOf '2026-11-02T09:45:00+08:00' -MaxRowsPerFile 3
```

第一条读取命令显示题面、文件引用和小案例；第二条只预览当时可见行，10:00才结束的30分钟特征不会在9:45出现。默认最多显示每文件3行，是预览上限，不是将股票池缩为3只。完整共享数据仍在包内。

需要导出完整可见输入时加`-ExportDirectory reports/local/selected-inputs`。不加`-AsOf`是离线全窗口序列，逐决策计算仍须按可见时间迭代，不可一次读入未来行当盘中已知特征。文件行序不保证是消息到达顺序，业务观测请按available_at排序并按event_id/execution_id去重。

从源码一键重建（已有同版本生成目录时使用`-Overwrite`）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-question-inputs.ps1 -Overwrite
```

只使用Windows自带PowerShell和.NET Framework，不需要Python或Node。配置见`config/input-generation.json`。

## 输入支持范围

|层|实际输入|边界|
|---|---|---|
|市场|240000条分钟线、日线、十档采样盘口、逐笔样本、质量/重建块、30分钟特征、主档/状态/日历等|全部synthetic；逐笔是采样重置块，不能当完整L3|
|业务|账户初态、母子单/请求、重复/乱序回报、查询、资金股份分录、交收流水|仅声明的测试规则和事件机制，不是实际柜台记录|
|辅助|规则包、阶段表、FIX测试报文、合成数据报、时钟/FPGA向量、假设profile与控制参数|不是实际交易所协议认证、硬件测量或市场校准|
|专用资产|独立衍生品合约/夜盘、海外加密持仓/费率、合成PCF/退补、大宗股份来源和确认|四种正常/部分失败/恢复/缺证据变体；不由股票冒充专用资产|
|逐题|115个独立小案例和1150题输入绑定|是基础输入与故障族上下文；不是每个技术节点具体故障都已精确复现|

`synthetic_input_ready=true`表示基础文件和小案例可读、已验收；`exact_node_fault_implemented=false`明确本版尚未覆盖每个节点精确故障；`real_dataset_ready=false`与`real_calibration_ready=false`保持真实来源边界。

最小真实字段只是起点。源字段在`synthetic/market`中沿用已确认表结构，实际原始价格单位仍需真实源核验；本包raw Wind映射整数价为分、价格除数100，分钟/日线价格和成交额为元，现金为整数分，股数为股。枚举使用SYN前缀，仅是测试方言。

校准/反解题不绑定含待推断参数的控制假设文件。没有真实校准样本或缺失数据的情形本身也是合法输入，题目不能据此要求一个假装可识别的真实参数。

内部校验摘要存于生成目录的`_internal`，不进入数据包或逐题输入。质量报告用于审计，不应作为求解特征传给模型。
