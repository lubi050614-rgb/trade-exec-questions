# 完善节点专用输入场景

## Why

当前每题已有共享基础数据和小案例，但共享的十类故障不能冒充115个节点的每种具体技术故障。需要按管线逐节点补专属数值、消息序列和对照输入。

## What Changes

- 为每节点至少准备正常、具体故障、恢复/反事实和缺证据四类输入。
- 精确场景完成后逐节点更新状态，保留未完成列表。
- 不生产该场景的答案或教师输出；内部一致性检查不作为求解标签暴露。
- 真实数据仍缺时允许test_only专用输入，但不提升真实证据等级。

## Capabilities

### New Capabilities

- `node-specific-inputs`：逐技术节点专用数值和故障输入的覆盖管理。

### Modified Capabilities

无。

## Impact

依赖基础输入包；扩展cases与消息/配置文件，保持1150问题ID和基础大universe不变。
