## Purpose

对每个技术节点的专用输入进行精确覆盖管理，避免把通用基础数据和故障族标签当作特定故障已实际复现。

## ADDED Requirements

### Requirement: 节点精确输入覆盖
系统 SHALL 为节点专用输入记录实际文件、正常/故障差异、时间单位与独立检查，未完成者保持精确场景未就绪。

#### Scenario: 只有通用重复回报
- **GIVEN** 节点需要特定的跨账户重复编号故障
- **WHEN** 数据仅包含同账户成交重复交付
- **THEN** 可以标记基础输入可用，不能标记该节点特定故障已精确复现

### Requirement: 不导出答案
节点输入 MUST 不包含该题标准答案、最终状态标签或内部真值路径，内部一致性检查和问题输入隔离。

#### Scenario: 新增节点恢复案例
- **GIVEN** 生成器内部能核验恢复后的状态
- **WHEN** 导出问题输入
- **THEN** 只导出初态、事件和必要给定信息，不导出作为求解目标的恢复最终状态
