## Purpose

管理尚未完成原始事件语义审查的节点，区分题目文件存在、输入投影一致、声明关系成立和完整故障因果可复现等不同证据等级，要求逐题可答性与独立业务验收都有记录后才能提升节点状态，保持任务进度与实际实现一致。

## ADDED Requirements

### Requirement: 逐节点审核记录
系统 SHALL 为待审节点记录十道题的输入充分性、单位、因果、不可识别项和独立验收；未完成者 MUST 保持pending_semantic_review。

#### Scenario: 批量输入已经存在
- **GIVEN** 某节点已有200标的五日输入但仅校验结构与投影
- **WHEN** 汇总语义审查状态
- **THEN** 该节点仍待审，不能仅由样本数量获得精确故障就绪标记
