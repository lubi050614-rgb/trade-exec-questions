# 逐节点语义验收

## Why

审查修复后将结构和声明关系检查与原始事件语义复算分开。P02-S01、P11-S05已有独立复算，其他113节点仍需检查故障成因、题干可答性及输入充分性，不能沿用此前全量精准覆盖的结论。

## What Changes

- 对113节点按管线逐项复核，并增加真正从事件/状态推导的独立验收。
- 处理主输入与共享背景的关联、缺证边界和潜在求解目标泄漏。
- 有证据才提升对应节点状态；保留题目ID及无答案交付边界。

## Capabilities

### New Capabilities
- `node-semantic-audit`: 逐节点语义审查与验收进度。

### Modified Capabilities
无。

## Impact

后续工作；不因本次五项审查修复而自动完成，不涉及教师生产和真实交易。
