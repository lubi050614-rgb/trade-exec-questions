# 修复题目与输入审查问题

## Why

审查发现跨通道故障成因矛盾、题号驱动场景错配、200股题仅有两笔记录、窗口校验依赖人工峰值及价格单位按数值外观解释。已有文件完整性证据不能等价于全部节点的语义验收。

## What Changes

- 重建可由原始事件复算的跨通道案例与窗口计数检查。
- 使用逐题显式场景清单，补齐两个200股题的五日账户/请求/限额输入。
- 显式声明实验价格单位，并按已实现的语义证据报告就绪状态。
- 保留题号、合成来源和不生成答案的边界。

## Capabilities

### New Capabilities
- `question-input-semantics`: 审查修复、原始数据复算与语义验收范围。

### Modified Capabilities
无。

## Impact

涉及配方、生成器、绑定器、读取器、校验器及交付报告；真实数据仍未接入。
