# 设计

场景选择以完整question_id查显式清单，不根据Q序号推断。无法匹配现有专用共享场景时不绑定该变体文件；专用主输入仍保留。批量题给出同一账户与版本的200标的请求、五日独立快照、逐股限额和并发尝试时间，不给执行结果。

跨通道案例使用已知接收时间的小订单簿轨迹，错误的全局seq排序保持各通道局部递增但改变跨通道顺序。校验从事件推导可见顺序和盘口轨迹。窗口计数从原始时间戳按半开滑动窗口重算，拒绝人为峰值一致却与事件不符的输入。

数值相同的20与20.0不得改变单位。每实验设置明确的默认价格单位，带_ticks/_major等后缀优先；价格除数与tick大小作为契约字段。

结构/配方一致性与业务语义验证分开。仅有通用关系比较的节点不自动获得精确故障已验证标记；新增逐节点待审清单。修复任务完成与其余节点语义审查是不同状态。
