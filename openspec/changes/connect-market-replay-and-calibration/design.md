# 设计

只读审计 → 事前冻结universe → 分片导出及源哈希 → 单位/枚举/可知时间确认 → 回放适配 → 队列/延迟/冲击敏感性 → 外部校准。schema、语义就绪、数据覆盖分别成门禁。

trade/order/quote的exchange_seq仅在确认的通道范围排序；同ts无全局顺序时保留偏序歧义。质量异常降级或隔离，不能静默补全。输入可以是脱敏离线文件，不强制访问数据库。

历史回放不反馈自身订单，避免无限复用深度；队列三档和冲击覆盖层均标为假设。真实自有母单/成交与保留日期用于校准，不能用生成真值自证市场。五日仅工程窗口，长期参数历史另取决策前数据。竞价专有数据和公告精确时间缺失时禁用对应预测结论。

真实规则及接口证据按D04/D05补证；硬件计时与虚拟延迟完全分开。外部数据未到位，允许完成适配与设计，不能勾选真实覆盖/实测验收任务。
