# 设计

选择每管线一题机制/实现和一题边界/不足，共26题。按节点所需证据提供最小输入，教师只接收可见数据，不接生成器ground_truth。模型调用配置从环境或私有路径读取，原始响应与核验报告按哈希关联。

启发式/schema/公式/状态断言先检查，再用独立参考或人工规则审查；不让同一生成逻辑当唯一评委。编造实测、超买超卖、未来泄漏、证据越界为硬失败。

先给节点family_id，再按模板和故障机制做跨节点近重复聚类，最后分配train/dev/test；不能仅凭节点ID保证所有近重复隔离。日期外集不足时不声称时间泛化。重试可恢复且每题幂等，不因格式修复重试覆盖已验收答案。

设计答案不伪造实验结果；执行证据等级依据真实产物提升。知识卡记录node_id、前置条件、数据契约、机制、动作、断言、失败/降级、证据等级和版本。
