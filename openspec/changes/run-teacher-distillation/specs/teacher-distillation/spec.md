## Purpose

按可追溯输入证据生产并独立核验教师答案，隔离同族样本和真值，生成保留条件、动作、失败路径与证据等级的学生知识卡。

## ADDED Requirements

### Requirement: 答案证据与版本追踪
教师流程 SHALL 记录每题模型、提示、数据和响应版本，并按实际证据声明设计、合成、回放或外部验证等级。

#### Scenario: 未提供可执行数据
- **GIVEN** 教师只收到schema和方案
- **WHEN** 生成答案
- **THEN** 答案保持design_only，不包含伪装实测的收益/成交/性能数字

### Requirement: 独立核验与防泄漏
流程 MUST 用独立断言/参考检查答案，并隔离同族场景、近重复模板和关联数据，真值不进入教师可见决策输入。

#### Scenario: 同故障的改写题
- **GIVEN** 两题共享节点或故障模板与路径
- **WHEN** 分配数据集
- **THEN** 同组隔离或明确标记不可作为独立泛化测试，不随机拆分后宣称能力提升
